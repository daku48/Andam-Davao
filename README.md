# Andam Davao

Disaster preparedness and evacuation assistance app for Davao City (Android, Kotlin, Jetpack Compose).

Be Ready. Be Safe. Be Andam.

## What it does

- Evacuation center directory and map, with Open / Full / Closed / Unknown status
- Nearest-first sorting and distance when location permission is granted
- Public announcements and alerts
- Live Davao weather (Open-Meteo, no API key needed)
- Emergency hotlines (tap to dial) and preparedness guides, which work offline
- Offline cache: the last good data is shown when there is no network, with a clear "saved data" banner
